Senku Cuts · last updated 22 September 2026

1. What this software is

Senku Cuts is a desktop application that runs on the owner's own computer. It prepares short vertical clips from the owner's own long-form gameplay recordings and uploads them to the owner's own TikTok account as drafts.

2. Who may use it

The application is built and operated for a single creator managing their own channel. It is not offered as a service to other people, has no user accounts, no registration, and no paid plans.

3. Content

All source recordings are created by the owner. The owner is solely responsible for the content processed and uploaded through this application and for complying with the rules of any platform it is uploaded to, including TikTok's Community Guidelines and Terms of Service.

The application uploads clips only as drafts. It never publishes anything on its own. Every post is reviewed and published manually by the account owner inside the TikTok application.

4. TikTok integration

The application uses TikTok's official APIs with permissions granted by the account owner:

  • user.info.basic — to confirm which account is connected.
  • video.upload — to place finished clips into that account's drafts.

Access can be revoked at any time from TikTok account settings, after which the application can no longer upload anything.
