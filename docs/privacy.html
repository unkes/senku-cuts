Privacy Policy

Senku Cuts · last updated 22 September 2026

Short version

The application runs entirely on the owner's own computer. It has no servers, no analytics, and no third parties. Nothing is collected about anyone.

What is stored, and where

  • Video files — source recordings and rendered clips stay in a folder on the owner's computer. They are never uploaded anywhere except to the owner's own TikTok drafts, on the owner's explicit action.
  • TikTok access token — received after the owner signs in with TikTok, stored locally on the same computer, and used only to upload clips to that same account.
  • Account display name and avatar — read once through user.info.basic so the application can show which account is connected. Not stored beyond the current session.

What is not done

  • No data is sent to the developer or to any analytics, advertising or tracking service.
  • No data about other TikTok users is requested, read or stored.
  • No content is published automatically — clips are uploaded as drafts only.

Deleting data

Revoking the application's access in TikTok account settings immediately stops all uploads. Deleting the application's local folder removes the stored token and every file it created.

Changes

If the application's behaviour changes, this page is updated. The current version is always available at this address.
